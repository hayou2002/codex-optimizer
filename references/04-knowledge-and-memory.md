# 知识与记忆

## 治理对象

- `$CODEX_HOME/AGENTS.md`：长期工作约定。
- `$CODEX_HOME/memories/`：Codex 生成记忆与证据。
- `$CODEX_HOME/skills/`：可执行知识与参考。
- 自动化任务模板与现有任务。
- 项目级 `AGENTS.md` 与 README。

## 原生优先

### 轻量操作

Codex 主目录是生成状态。优先使用 `/memories` 和 Personalization 设置做查看、开关、memory 使用与生成控制。原生入口没有支持的精细编辑时，才使用受控文件通道。

### 记忆结构

不要把记忆当成持久规范唯一来源。必须始终执行的规则放 `AGENTS.md` 或项目文档；记忆用于召回和经验。

## 审计

只读记录：

- 文件体量、条目数、mtime 与 hash
- 完全重复项
- 冲突候选
- 失效路径或版本引用
- 极少使用信号（只作为线索）
- 同一事实在 `AGENTS.md`、skills、记忆中的多源漂移

不要只凭文件年龄判断过期。

## 操作

支持：去重、合并、压缩、拆分、降权、退役、删除、消冲突、类目修复和格式修复。

自动执行仅限：

- 字节级完全重复条目的确定性合并。
- 不改变事实的格式规范化。
- 已由现场验证明确失效的路径清理，前提是没有独有证据。

压缩、语义合并、拆分、降权、冲突处理、删除和整库重置先输出差异与证据，确认后执行。

## 冲突与过时

- 现场可验证事实优先于记忆记录。
- 不可验证的冲突保留双方并标待裁决。
- 取代不等于删除；可保留失效历史，但避免重复注入。
- 从派生文件推断出的事实应回写到合适真源，而非无限堆积派生。

不要手工编辑会话数据库或生成 SQLite；需要清理时通过原生控制面重置。

## 直改生成记忆文件

获准的受控直改流程：

1. 编辑前记录原内容或 path、size、mtime；只有同一路径并发冲突、跨盘后删源或需要发布完整性时才强校验 SHA256。
2. 同一事务内保存可恢复的原文本快照；不再给每次普通编辑另生成第二份文件备份。
3. 使用临时文件原子替换。
4. 保留 manifest 和差异摘要。
5. 下次运行发现 hash 与记录不一致时报告，说明 Codex 可能后台重写。

低风险确定性重复/格式修复可自动；其他编辑先确认。备份不能覆盖高风险保护：认证、数据库、会话和密钥永不进入记忆编辑通道。

## 知识分层

- 始终生效的纪律 -> `AGENTS.md`。
- 可执行流程 -> skill。
- 临时召回与经验 -> Codex memories。
- 项目事实 -> 项目 README/source。

保持短入口、详细参考和明确引用，避免把整个规范复制到每个项目。
